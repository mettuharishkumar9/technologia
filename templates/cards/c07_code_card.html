Automatic CDF
Row-level changes from table_changes(). No CDF flag needed.
Legacy CDF
  • Enable per table, up front
  • Changes computed at write time
  • Extra write time and storage
Automatic CDF
  • Any UC table with row tracking
  • Changes computed at query time
  • Faster MERGE / UPDATE writes
example.sql 
CREATE TABLE orders (order_id INT, status STRING)
TBLPROPERTIES ('delta.enableRowTracking' = 'true');

INSERT INTO orders VALUES (1, 'placed'), (2, 'placed');
UPDATE orders SET status = 'shipped' WHERE order_id = 1;
DELETE FROM orders WHERE order_id = 2;

SELECT _commit_version AS v, _change_type, order_id, status
FROM table_changes('orders', 2) ORDER BY v, _change_type DESC;
