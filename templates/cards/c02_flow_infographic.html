From agent idea to deployable AI agent
A code-first workflow to build, test and deploy custom AI agents on Databricks.
New
Scaffold, run and deploy agents from your terminal.

Initialize
Create an agent project
terminal
pip install \
  databricks-agentbricks

agentbricks init \

  my-agent
Scaffold a project from a LangGraph or OpenAI Agents SDK template.
2
Develop
Run and test locally
Local dev server with a chat UI for quick iteration.
terminal
